# 《迷雾突围》平衡调优记录

## 当前版本参数

- 回合数：10
- 目标进度：15
- 初始体力：6
- 初始补给：3
- 风险阈值：10
- 调权范围：0.85 ~ 1.15
- 首局保护：0.6

## 调优方法

1. 运行 `npm run simulate`
2. 观察胜率、失败原因占比
3. 调整：
   - 事件权重
   - 行动权重偏移
   - 后段压力系数
4. 重复仿真直到进入目标区间

## 目标区间

- 新手首局胜率：20%~35%
- 熟悉后胜率：40%~55%
