# 《迷雾突围》视觉方向（非极简吸引力版）

## 1. 视觉关键词

- 深雾压迫
- 冷色高科技
- 发光信息层
- 动态扫描感
- 危险可视化

---

## 2. 风格主张

不是“空白+几条线”的极简风。  
MVP 采用“**重氛围 + 清信息**”路线：

1. 背景具备体积感（多层迷雾）
2. HUD 具备游戏感（发光、描边、渐变）
3. 状态变化具备情绪感（风险脉冲、扫描流动）
4. 保持玩法可读（文本区稳定、对比充足）

---

## 3. 色彩系统

- 背景主色：`#0d1326 -> #180f25`（纵向深渐变）
- 雾层主色：青蓝 / 紫蓝半透明
- 强调色：`#5ee8c2`（进度、正向反馈）
- 警示色：`#ffb35e`（中压）
- 危险色：`#ff6478`（风险临界）
- 正文：`#e6f0ff`
- 次文：`#9fb0cf`

---

## 4. 动效原则（轻量）

## 4.1 必备动效

1. 背景雾层缓慢漂移
2. 扫描线自上而下循环
3. 关键数字轻发光

## 4.2 条件动效

- 风险 >= 7：风险数字增强发光并轻脉冲
- 终局成功/失败：标题高亮色切换

## 4.3 性能预算

- 粒子（雾团）控制在 20~24
- 动效计算不使用复杂后处理
- 低端机降级策略：
  - 关闭扫描线与次级雾层
  - 保留进度条与风险颜色反馈

---

## 5. 页面视觉重心

## 首页
- 第一视觉：游戏名 + 卖点文案
- 第二视觉：开始突围按钮（主 CTA）

## 对局
- 第一视觉：行动按钮区（底部）
- 第二视觉：资源卡与进度条
- 第三视觉：事件和战术画像（解释层）

## 结算
- 第一视觉：结果标题
- 第二视觉：系统观察报告
- 第三视觉：再来一局按钮

---

## 6. 反例约束

以下表现禁止：
1. 过多高频闪烁（影响阅读）
2. 仅追求酷炫导致按钮不可辨识
3. 文案对比不足
4. 动效遮挡核心数据
