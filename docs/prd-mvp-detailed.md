# 《迷雾突围》MVP 详细 PRD（可开发版）

## 1. 目标与版本范围

- 版本：V0.1（MVP 可玩原型）
- 平台：微信小游戏
- 单局目标：10 回合内将进度推进到 15
- 单局时长：3~5 分钟

MVP 只验证：
1. 规则循环是否成立并可复玩
2. 玩家是否能感知“环境在回应我”
3. 适应机制是否不破坏成就感

---

## 2. 核心状态机

## 2.1 页面状态

- `HOME`：首页，开始按钮 + 玩法说明
- `BATTLE`：对局中
- `RESULT`：结算页（成功 / 失败 + 系统观察报告）

页面流转：
`HOME -> BATTLE -> RESULT -> BATTLE(再来一局)`

## 2.2 回合状态

每回合固定流程：
1. 展示资源与 3 个行动选项
2. 玩家选择 1 个行动
3. 执行动作结算（基础效果 + 随机分支）
4. 触发事件结算（环境反馈）
5. 判断胜负
6. 未结束则进入下一回合

---

## 3. 资源与边界规则

## 3.1 初始值

- 体力：6
- 补给：3
- 风险：0
- 进度：0

## 3.2 胜负规则（优先级）

每回合结算后按以下顺序判断：
1. 体力 `<= 0` -> 失败（体力耗尽）
2. 风险 `>= 10` -> 失败（风险失控）
3. 进度 `>= 15` -> 胜利（成功突围）
4. 若已是第 10 回合且进度 `< 15` -> 失败（撤离超时）

> 说明：失败条件优先于胜利条件，用于保持规则一致性与可解释性。

## 3.3 资源夹逼（防异常）

引擎内部限制：
- 体力：[-5, 12]
- 补给：[0, 12]
- 风险：[0, 15]
- 进度：[0, 20]

---

## 4. 行动系统

## 4.1 行动定义

1. 前进：进度 +2，体力 -1，风险 +1
2. 搜索：补给 +2，25% 概率额外风险 +2
3. 休整：体力 +2，补给 -1
4. 绕路：进度 +1，体力 -1，风险 -1
5. 冲刺：进度 +3，体力 -2，风险 +2
6. 强搜：补给 +3，风险 +2，10% 概率额外体力 -1

## 4.2 可用性规则

- 休整要求补给 >= 1
- 前进/绕路要求体力 >= 1
- 冲刺要求体力 >= 2
- 搜索/强搜无额外前置

不可用行动不进入候选池。

## 4.3 行动池规则

- 每回合展示 3 个可选行动
- 同一回合内同 action 不重复
- 通过权重随机抽样生成（会受风格识别影响）

---

## 5. 风格识别系统

## 5.1 标签类型

- 搜索型（searcher）
- 冲刺型（sprinter）
- 保守型（conservative）
- 混合型（mixed）

## 5.2 识别机制

- 识别窗口：最近 4 次行动
- 更新周期：每 2 回合更新一次
- 计分映射：
  - 搜索 / 强搜 -> 搜索型分
  - 前进 / 冲刺 -> 冲刺型分
  - 休整 / 绕路 -> 保守型分
- 判定规则：
  - 最高分 < 2 -> 混合型
  - 最高分与次高分持平 -> 混合型
  - 否则为最高分类别

---

## 6. 动态调权系统

## 6.1 调权对象

- 行动池权重
- 事件池权重
- 事件数值偏置（单项不超过 1）

## 6.2 调整幅度约束

- 权重乘子限制在 `[0.85, 1.15]`
- 首局保护系数：0.6（调权力度打折）
- 第 8~10 回合统一增加推进压力（弱提升）

## 6.3 风格策略（软反制）

- 搜索型：
  - 下调搜索/强搜
  - 上调前进/冲刺
  - 风格响应事件更常见
- 冲刺型：
  - 上调休整/绕路
  - 高压事件增加
- 保守型：
  - 下调保守动作
  - 上调推进动作与后段压力
- 混合型：
  - 保持中性

---

## 7. 环境状态与前台表达

环境状态机：
- `未明显识别`：1~3 回合或风格为混合型
- `适应中`：4~7 回合且风格非混合
- `已响应`：8~10 回合且风格非混合

局内战术画像显示：
- 当前风格
- 环境状态
- 解释文案（可验证，不伪玄学）

---

## 8. 失败归因规则

按最终失败类型生成可解释归因：
- 体力耗尽：末段过度冲压、恢复不足
- 风险失控：中后段风险持续抬升未削峰
- 撤离超时：中段推进不足、后段被迫追赶

局后报告包含：
1. 主要风格
2. 环境开始适应的回合
3. 关键行为链路（近 4 回合）
4. 下一局建议（最多 3 条）

---

## 9. 首局保护机制

首局启用：
1. 调权力度降低（×0.6）
2. 风格响应不会过早拉高难度
3. 后段保留翻盘事件机会

目标：首局先学规则，不制造“被系统针对”的强挫败。
